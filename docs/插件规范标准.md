# SweetReader 插件规范标准（Plugin Specification）

> 版本：v1.0 ｜ 适用：SweetReader v2.3+ 插件框架
> 本文是插件开发的**权威规范**。照着写，别人一眼就能看懂、能复用、能提交。
> 配套快速上手见《插件开发指南》。

---

## 1. 定位与范围

插件（Plugin）是 SweetReader 的**一等扩展单元**：在不改动核心代码的前提下，给阅读器追加页面、入口、按钮与可配置功能。

- 插件运行在应用进程内，拥有与应用同等的数据库、模型与文件系统访问能力（见 §6）。
- 插件必须**可独立启用 / 停用**，导入失败不得影响其它插件或核心功能。
- 插件带来的任何功能，都**应当提供图形化控制界面**（见 §5）。

---

## 2. 目录与自动发现

框架按以下顺序扫描，越靠后优先级越高（后发现的同名 id 覆盖前者）：

| 位置 | 路径（容器内） | source 标记 | 说明 |
|------|------|------|------|
| 内置插件 | `app/plugins/builtin/` | `builtin` | 随代码仓库，需发版更新 |
| 随包用户插件 | `app/plugins/user/` | `user` | 随代码同步部署，无需改动容器 |
| **用户自放插件** | `instance/plugins/` | `user` | **持久目录，重新部署不丢**，放入文件即可用 |

发现规则：

- 单文件 `xxx.py` 或包目录 `xxx/`（含 `__init__.py`），文件名即模块名。
- 模块必须定义顶层常量 `PLUGIN = Plugin(...)`，否则被忽略。
- 包目录同样需要在 `xxx/__init__.py` 里定义 `PLUGIN`。
- 以 `_` 开头的文件会被忽略。

在「插件管理」页点「重新扫描插件目录」即可即时发现新插件，**无需重启**（蓝图会在扫描时动态注册）。

## 3. Plugin 对象字段规范

每个插件在模块内构造一个 `Plugin` 实例：

```python
from app.plugins import Plugin, PluginEntry

PLUGIN = Plugin(
    id='my_plugin',            # 唯一标识，全小写蛇形，必填
    name='我的插件',           # 显示名，必填
    description='一句话说明',   # 管理页展示，建议填
    version='1.0.0',           # 语义化版本号（见 §9），默认 1.0.0
    author='你的名字',         # 建议填，管理页展示
    homepage=[...],            # 可选：首页扩展面板入口
    blueprint=...,             # 可选：独立页面 Blueprint
    reader_tools=[...],        # 可选：阅读页工具栏按钮
    admin_nav=[...],           # 可选：管理员侧栏链接
    settings_schema=[...],     # 可选：图形化设置表单（见 §5）
    settings_blueprint=...,    # 可选：完全自定义设置页（见 §5.4）
    enabled_by_default=True,   # 默认是否启用
    # source / error 由框架填写，不要自己声明
)
```

### 3.1 必填与命名约束

- `id`：长度 ≤ 40，仅 `[a-z0-9_]`，**全站唯一**。冲突时后加载者覆盖。
- `name`：≤ 30 字。
- `version`：必须符合语义化版本 `MAJOR.MINOR.PATCH`（如 `1.2.0`）。

### 3.2 能力字段（均为可选）

| 字段 | 类型 | 作用 |
|------|------|------|
| `homepage` | `List[PluginEntry]` | 首页「扩展功能」面板露出卡片 |
| `blueprint` | Flask `Blueprint` | 拥有独立路由 + 模板 + 静态资源 |
| `reader_tools` | `List[dict]` | 阅读页底部工具栏按钮 |
| `admin_nav` | `List[dict]` | 管理员侧栏链接 |
| `settings_schema` | `List[dict]` | 框架自动渲染的图形化设置表单 |
| `settings_blueprint` | Flask `Blueprint` | 完全自定义的设置页 |

## 4. 各能力详解

### 4.1 首页入口 `homepage`

`PluginEntry(label, widget='', url='', html_url='', order=0)`

- `url`：点击跳转到某页面（最常用）。
- `html_url`：返回一段 HTML 片段的端点，前端拉取后注入卡片（适合做小组件 / 实时数据）。
- `widget`：复用内置小组件键（`recent` / `random` / `related`）。
- `order`：越小越靠前。

### 4.2 独立页面 `blueprint`

普通 Flask Blueprint。**路由建议统一加 `/plugin/` 前缀**，避免与核心或其它插件冲突：

```python
bp = Blueprint('my_plugin', __name__, template_folder='templates')

@bp.route('/plugin/my-page')
@login_required
def page():
    return render_template('my_page.html', ...)
```

模板放插件目录下的 `templates/`，静态资源用 `static_folder`。

### 4.3 阅读页按钮 `reader_tools`

```python
reader_tools=[{'label': '我的按钮', 'url': '/plugin/my-page', 'icon': '⭐'}]
```

渲染在阅读页底部工具栏右侧。

### 4.4 管理侧栏 `admin_nav`

```python
admin_nav=[{'label': '我的管理项', 'url': '/plugin/my-admin'}]
```

仅对管理员显示，注入管理员侧栏。

## 5. 图形化设置（重点）

**规范：插件若带可调参数，必须用 `settings_schema` 声明，由框架在「插件管理」页自动渲染表单。** 用户改完即时保存，插件无需写任何前端。

### 5.1 字段声明

```python
settings_schema = [
    {'key': 'topN', 'label': '热门分类数量', 'type': 'int',
     'default': 8, 'min': 1, 'max': 50, 'help': '展示前 N 个'},
    {'key': 'show_format', 'label': '显示格式分布', 'type': 'bool', 'default': True},
    {'key': 'theme', 'label': '配色', 'type': 'select', 'default': 'auto',
     'options': [{'value': 'auto', 'label': '跟随系统'},
                 {'value': 'light', 'label': '浅色'},
                 {'value': 'dark', 'label': '深色'}]},
    {'key': 'note', 'label': '备注', 'type': 'textarea', 'default': ''},
    {'key': 'title', 'label': '标题', 'type': 'text', 'default': '默认标题'},
]
```

支持的 `type`：`text` / `int` / `float` / `bool` / `select` / `textarea`。

每个字段的键：`key`（必填，蛇形）/ `label`（必填，显示名）/ `type` / `default` / `help`（可选说明）/ `min`·`max`（int、float 可选）/ `options`（select 必填）。

### 5.2 读取设置

```python
from app.plugins import registry, get_plugin_settings

cfg = get_plugin_settings('my_plugin')      # 或 registry.get_settings('my_plugin')
top_n = int(cfg.get('topN', 8))             # 永远有默认值兜底
show = bool(cfg.get('show_format', True))
```

- 返回值是**合并默认值后**的字典，缺字段用 `default`。
- 请在请求上下文内调用（设置持久化依赖 `current_app`）。

### 5.3 持久化

- 存储位置：`instance/plugins_state.json`，结构为
  `{"<plugin_id>": {"enabled": true, "settings": {"topN": 8}}}`。
- 与默认值相同的项不落盘，存储保持精简。
- 升级插件时，新增字段用默认值；已删除字段自动忽略。

### 5.4 自定义设置页（高级）

通用表单不够用时，可声明 `settings_blueprint`（一个 Blueprint，路由建议 `/plugin/<id>/settings`），完全自定义界面，自行通过 `POST /api/plugins/<id>/settings` 保存或读 `get_plugin_settings`。管理页会显示「自定义设置页 ↗」链接。

## 6. 插件可用上下文（白名单 API）

插件模块内可直接 import：

```python
from app.plugins import registry, get_plugin_settings   # 框架
from app.models import Book, Category, User, ReadingProgress, db   # 数据模型
from flask_login import current_user                     # 当前登录用户
from flask import Blueprint, render_template, request, jsonify, current_app
```

- `Book`：书籍模型（`id, title, author, filename, file_type, category_id, relative_path, ...`）。
- `Category`：分类（`name, path, parent_id, level, book_count`）。
- `User`：用户（`is_admin, is_sub_admin, can_import, can_export` 等能力位）。
- `db.session`：直接查询 / 写入。注意**大书库写操作需谨慎**（见 §8）。
- 所有页面路由都应加 `@login_required`，并按需判断 `current_user.is_admin`。

---

## 7. 管理页规范

「插件管理」（管理员可见）提供：

1. 插件列表：显示名、版本、**来源徽章（内置 / 用户）**、描述、作者、能力标识、导入失败标红。
2. **启用 / 停用**开关，即时生效。
3. **图形化设置表单**：有 `settings_schema` 的插件直接在此配置。
4. **重新扫描插件目录**：发现新放入的插件并动态注册蓝图。
5. **自定义设置页**链接（若插件声明了 `settings_blueprint`）。
6. **上传插件**：直接上传单个 `.py` 或 `.zip` 包，校验后自动放入用户插件目录。

---

## 8. 安全与约束

1. **权限**：插件即代码，拥有进程内完整权限（数据库、文件系统、网络）。只安装可信来源的插件。
2. **隔离**：当前无沙箱，部署形态决定隔离强度；放入他人插件前请先阅读代码。
3. **容错**：单个插件导入 / 运行异常只影响该插件，管理页标红，其余正常。
4. **大书库**：查询避免 `N+1` 与全表扫描；写入注意扫描线程可能持有数据库写锁，长事务会卡住。
5. **路由冲突**：插件路由加 `/plugin/` 前缀；Blueprint 名全局唯一。
6. **不触碰核心**：插件不应 import 并改写 `app/routes.py` 等核心文件。
7. **外网**：翻译 / 联网类功能需自行处理无外网环境（默认不可用）。

---

## 9. 版本与发布

- `version` 必须语义化：`MAJOR.MINOR.PATCH`。
  - MAJOR：不兼容变更；MINOR：新增能力；PATCH：修复。
- 插件变更请在 `CHANGELOG.md` 中说明。

## 10. 最小可运行示例

完整示例见 `app/plugins/user/book_stats.py`（书库统计：总量 / 格式 / 热门分类 / 最近入库，带图形化设置）。

```python
from flask import Blueprint, render_template
from flask_login import login_required
from app.models import Book, db
from app.plugins import Plugin, PluginEntry, registry

bp = Blueprint('demo', __name__, template_folder='templates')

@bp.route('/plugin/demo')
@login_required
def page():
    cfg = registry.get_settings('demo')
    limit = int(cfg.get('limit', 10))
    books = Book.query.order_by(Book.id.desc()).limit(limit).all()
    return render_template('demo.html', books=books)

PLUGIN = Plugin(
    id='demo', name='示例插件', description='演示最小插件',
    version='1.0.0', author='you',
    homepage=[PluginEntry(label='示例', url='/plugin/demo')],
    blueprint=bp,
    settings_schema=[
        {'key': 'limit', 'label': '展示数量', 'type': 'int', 'default': 10, 'min': 1, 'max': 100},
    ],
)
```

## 11. 发布前自检清单（Checklist）

- [ ] `id` 唯一、蛇形、≤ 40 字符
- [ ] `version` 为合法语义化版本
- [ ] 所有页面路由加 `@login_required`，管理员功能校验 `is_admin`
- [ ] 路由加 `/plugin/` 前缀，Blueprint 名唯一
- [ ] 可调参数都用 `settings_schema` 声明，并在代码里用 `get_plugin_settings` 读取
- [ ] 已自测：启用 / 停用 / 重新扫描 / 设置保存 / 页面渲染
- [ ] 导入失败不影响其它插件（异常被框架捕获）
- [ ] 大书库查询无全表扫描 / N+1
- [ ] 在 `CHANGELOG.md` 中说明本次变更
