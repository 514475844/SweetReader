# SweetReader 插件开发指南（快速上手）

> 📌 权威规范与全部字段 / 约束见 **《插件规范标准》**（`docs/插件规范标准.md`），本文是它的快速上手版。
> 插件框架已就绪：你可以自己写插件，**无需改框架代码、无需重新打包镜像**。

## 一、把插件放哪

两种位置，效果一样（都会被自动发现，并可在「插件管理」中开关）：

| 位置 | 路径（容器内） | 适合 |
|---|---|---|
| 随包发布 | `app/plugins/user/`（镜像内） | 想跟着代码一起走、能进 Docker 镜像的插件 |
| 自己放文件 | `instance/plugins/` | 仅自己用、不想进代码的插件（持久目录，重新部署不丢） |

文件命名：`<插件名>.py`，例如 `my_tool.py`。以 `_` 开头的文件会被忽略。

**放入之后**：进「插件管理」点「重新扫描」即可发现并生效，无需重启。

## 二、一个插件长什么样

```python
from flask import Blueprint, render_template
from flask_login import login_required
from app.models import Book, db
from app.plugins import Plugin, PluginEntry

bp = Blueprint('my_tool', __name__, template_folder='templates')

@bp.route('/plugin/my-tool')
@login_required
def page():
    n = Book.query.count()
    return render_template('my_tool.html', n=n)

PLUGIN = Plugin(
    id='my_tool',                       # 全局唯一 ID
    name='我的工具',
    description='一句话说明',
    version='1.0.0',
    author='你',
    homepage=[PluginEntry(label='我的工具', url='/plugin/my-tool', order=50)],
    admin_nav=[{'label': '我的工具', 'url': '/plugin/my-tool'}],   # 管理员侧栏入口
    reader_tools=[{'label': '工具', 'url': '/plugin/my-tool'}],    # 阅读页工具栏按钮
    blueprint=bp,                       # 自定义页面 / 路由
    enabled_by_default=True,
)
```

- `homepage`：首页「扩展功能」面板入口（`url` 跳转 / `widget` 内置小组件 / `html_url` 拉取 HTML 片段注入）。
- `blueprint`：Flask Blueprint，插件拥有自己的路由 + 模板 + 静态资源。模板放同级 `templates/`，静态资源放 `static/`。
- `admin_nav` / `reader_tools`：`{label, url}` 列表，分别注入管理员侧栏、阅读页工具栏。
- 不需要的能力就删掉对应字段。

## 三、图形化设置（推荐这样做）

**插件带可调参数，就用 `settings_schema` 声明**，框架会在「插件管理」页自动渲染成表单，用户改完即时保存，你不用写任何前端。

```python
settings_schema = [
    {'key': 'limit', 'label': '展示数量', 'type': 'int', 'default': 10, 'min': 1, 'max': 100},
    {'key': 'show_format', 'label': '显示格式分布', 'type': 'bool', 'default': True},
    {'key': 'theme', 'label': '配色', 'type': 'select', 'default': 'auto',
     'options': [{'value': 'auto', 'label': '跟随系统'}, {'value': 'light', 'label': '浅色'}]},
    {'key': 'note', 'label': '备注', 'type': 'textarea', 'default': ''},
]
```

支持类型：`text` / `int` / `float` / `bool` / `select` / `textarea`。

读取：

```python
from app.plugins import get_plugin_settings
cfg = get_plugin_settings('my_tool')
limit = int(cfg.get('limit', 10))
```

通用表单不够用时，可声明 `settings_blueprint`（自定义设置页），管理页会显示「自定义设置页 ↗」链接。详见规范 §5。

## 四、能用到什么

- 数据：`from app.models import Book, Category, User, ReadingProgress, db`
- 当前用户：`from flask_login import current_user`
- 框架：`from app.plugins import Plugin, PluginEntry, registry, get_plugin_settings`
- 路由正常加 `@login_required`；管理员功能再判断 `current_user.is_admin`。

## 五、示例插件

仓库自带 `app/plugins/user/book_stats.py`（书库统计：总量 / 格式 / 热门分类 / 最近入库，带图形化设置），是完整范例。

在「插件管理」确认「书库统计」已启用；首页扩展功能面板、管理员侧栏、阅读页工具栏都会出现入口，且可在管理页直接配置它的选项。

## 六、排错与注意

- 导入失败不会拖垮应用：会在「插件管理」页标红并显示错误，其余插件照常。
- 仅新增插件文件时，用「重新扫描」即可；改动蓝图或模板建议重启容器后再验证。
- 页面报 500：先看容器日志（`docker logs <容器名> --tail 50`）。
- 插件与核心应用运行在同一进程内，请只做本地书库相关的轻量功能。
